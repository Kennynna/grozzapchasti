# grozzapchasti

Монорепозиторий: витрина запчастей и NestJS API в одном git.

| пакет | стек | как запустить |
|---|---|---|
| `front/` | Vite, React 19 | `cd front && pnpm dev` — :5173 |
| `backend/` | NestJS 11, Prisma, Postgres | `cd backend && npm run start:dev` — :4060 |

План: [`PLAN.md`](./PLAN.md). Деплой: [`DEPLOY.md`](./DEPLOY.md). API для фронта: [`front/BACKEND.md`](./front/BACKEND.md). UI: [`front/FRONT.md`](./front/FRONT.md).
